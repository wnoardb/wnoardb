## 🚀 Projeto em destaque

### 📦 Relp!

**Relp!** foi meu principal projeto desenvolvido durante o Técnico em Desenvolvimento de Sistemas.

Atuei como **Desenvolvedor Back-End**, participando da construção de um sistema voltado para a gestão de microempresas.

O projeto envolveu:

- Controle de estoque
- Registro de vendas
- Controle de caixa
- Dashboard com indicadores
- Aplicação Web
- Aplicativo mobile
- Banco de dados MySQL
- Desenvolvimento em equipe utilizando Scrum

No projeto, trabalhei principalmente com **Back-End, lógica de negócio, integração com banco de dados e desenvolvimento de funcionalidades da aplicação**.
